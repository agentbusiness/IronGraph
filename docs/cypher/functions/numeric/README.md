# Numeric functions

Use these scalar functions to transform values within a query. Every page states accepted arguments,
null behavior, limits and two self-contained examples.

| Function | Signature | Purpose |
| --- | --- | --- |
| [`abs`](./abs.md) | `abs(number)` | Return the non-negative magnitude of a number. |
| [`acos`](./acos.md) | `acos(number)` | Return the inverse cosine in radians. |
| [`asin`](./asin.md) | `asin(number)` | Return the inverse sine in radians. |
| [`atan`](./atan.md) | `atan(number)` | Return the inverse tangent in radians. |
| [`atan2`](./atan2.md) | `atan2(y, x)` | Return the angle in radians for two coordinates, preserving the quadrant. |
| [`ceil`](./ceil.md) | `ceil(number)` | Round a number toward positive infinity. |
| [`floor`](./floor.md) | `floor(number)` | Round a number toward negative infinity. |
| [`round`](./round.md) | `round(number)` | Round to the nearest integral value, with halfway cases away from zero. |
| [`sign`](./sign.md) | `sign(number)` | Return -1, 0 or 1 according to the sign of a number. |
| [`sqrt`](./sqrt.md) | `sqrt(number)` | Return the square root. |
| [`exp`](./exp.md) | `exp(number)` | Return e raised to a numeric power. |
| [`log`](./log.md) | `log(number)` | Return the natural logarithm. |
| [`log10`](./log10.md) | `log10(number)` | Return the base-ten logarithm. |
| [`power`](./power.md) | `power(base, exponent)` | Raise a numeric base to a numeric exponent. |
| [`sin`](./sin.md) | `sin(radians)` | Return the sine of an angle in radians. |
| [`cos`](./cos.md) | `cos(radians)` | Return the cosine of an angle in radians. |
| [`tan`](./tan.md) | `tan(radians)` | Return the tangent of an angle in radians. |
| [`cot`](./cot.md) | `cot(radians)` | Return the reciprocal of the tangent. |
| [`degrees`](./degrees.md) | `degrees(radians)` | Convert radians to degrees. |
| [`radians`](./radians.md) | `radians(degrees)` | Convert degrees to radians. |
| [`pi`](./pi.md) | `pi()` | Return the mathematical constant pi. |
| [`e`](./e.md) | `e()` | Return the base of natural logarithms. |
| [`rand`](./rand.md) | `rand()` | Return a new pseudo-random floating-point value in the interval [0, 1). |
