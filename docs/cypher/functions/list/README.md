# List functions

Use these scalar functions to transform values within a query. Every page states accepted arguments,
null behavior, limits and two self-contained examples.

| Function | Signature | Purpose |
| --- | --- | --- |
| [`head`](./head.md) | `head(list)` | Return the first list element. |
| [`last`](./last.md) | `last(list)` | Return the last list element. |
| [`tail`](./tail.md) | `tail(list)` | Return the list without its first element. |
| [`reverse`](./reverse.md) | `reverse(listOrText)` | Reverse list elements or string characters. |
| [`range`](./range.md) | `range(start, end [, step])` | Build an inclusive sequence of integers. |
| [`isEmpty`](./isempty.md) | `isEmpty(listOrMapOrText)` | Test whether a list, map or string contains no entries or characters. |
| [`size`](./size.md) | `size(listOrMapOrText)` | Count list elements, map entries or string characters. |
| [`length`](./length.md) | `length(pathOrListOrMapOrText)` | Count relationships in a path, or entries in a list, map or string. |
