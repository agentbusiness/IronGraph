# Shortest-path procedures

One route between two nodes, or the cheapest cost to everywhere from one node. The difference between them is what "shortest" is measured in: relationships, or the value of a relationship property.

| Page | Summary | Standard |
| --- | --- | --- |
| [`graph.shortestpath`](./graph-shortestpath.md) | One path with the fewest relationships between two nodes, and its length. | extension |
| [`graph.dijkstra`](./graph-dijkstra.md) | The cheapest cost from one source to every reachable node, measured by a numeric relationship property. | extension |
