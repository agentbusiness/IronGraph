# Local structure procedures

How tightly knit the graph is, measured three ways: closed triangles across the whole graph, the same idea per node, and how deep into a densely connected core each node survives.

| Page | Summary | Standard |
| --- | --- | --- |
| [`graph.trianglecount`](./graph-trianglecount.md) | One number: how many closed triangles the whole graph contains. | extension |
| [`graph.clusteringcoefficient`](./graph-clusteringcoefficient.md) | Per node, the share of its neighbours that are connected to each other. | extension |
| [`graph.kcore`](./graph-kcore.md) | How deep into the graph's densely connected interior each node survives. | extension |
